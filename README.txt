Drude-Stundenzettel als installierbare App (PWA)

1) Auf GitHub ein neues Repository anlegen (z. B. "Drude-Stundenzettel").
2) "Add file > Upload files": ALLE Dateien aus diesem Ordner hochladen
   (index.html, manifest.webmanifest, sw.js, 3 PNG-Dateien) und "Commit" klicken.
3) Settings > Pages > Source: "Deploy from a branch", Branch "main", Ordner "/ (root)", Save.
4) Nach ca. 1 Minute ist die App unter https://<DEIN-NAME>.github.io/stundenzettel/ erreichbar.

Installieren:
- Android (Chrome): Menü (drei Punkte) > "App installieren" bzw. "Zum Startbildschirm".
- iPhone/iPad (Safari): Teilen-Symbol > "Zum Home-Bildschirm".
- PC (Chrome/Edge): Installieren-Symbol rechts in der Adressleiste.

Wichtig: Die Daten liegen nur im jeweiligen Browser/der jeweiligen App auf dem Gerät.
Zwischen Geräten und beim ersten Start der installierten App: "Sichern" und dann "Laden".
Auf dem iPhone hat die Home-Bildschirm-App einen eigenen Speicher, getrennt von Safari.
